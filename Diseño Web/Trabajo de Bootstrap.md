Se puede realizar en parejas. Usar plantillas de Bootstrap, junto a contenido ya visto antes, para elaborar un proyecto de web, asignado por el docente de entre los siguientes (podrá ser realizado en pareja):

Web de ventas de libros, con carrito, facturas y detalles de envío.
Web de reserva de parking en aeropuerto, con detalles de vuelo, datos de pasajero y del avión.
Web de compras de artículos, con carrito, facturas y detalles de envío. 
Web de venta de productos de segunda mano, con detalles de producto, de comprador, zona de entrega (opción con dirección y locker).

Preguntas del docente: hasta 20%
