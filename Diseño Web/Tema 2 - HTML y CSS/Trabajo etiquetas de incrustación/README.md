# Trabajo: etiquetas de incrustación

Web sencilla de **dos niveles** (una pagina enlaza con la otra) que usa las etiquetas de
contenido incrustado del epigrafe 6 de HTML (tabla 6.1).

## Archivos

```
Trabajo etiquetas de incrustación/
├── index.html   Nivel 1 - Algeciras Digital
├── detalle.html Nivel 2 - El Puerto de Algeciras
├── assets/      imagenes, video, audio y ficha tecnica
├── capturas/    capturas de pantalla
└── Trabajo etiquetas de incrustación - Capturas.pdf
```

## Etiquetas usadas (tabla 6.1)

- `<img>`: logotipo y fotos.
- `<iframe>`: mapa de Google Maps.
- `<video>` y `<source>`: video de ejemplo.
- `<audio>` y `<source>`: audio de ejemplo.
- `<canvas>`: lienzo para dibujar.
- `<embed>`: ficha tecnica en PDF.
- `<object>`: ficha tecnica en PDF (con texto alternativo).
- `<svg>`: dibujo vectorial.

Ademas se usan titulos, parrafos, enlaces, una tabla y estilos basicos con `<style>`.
No se usa JavaScript.
