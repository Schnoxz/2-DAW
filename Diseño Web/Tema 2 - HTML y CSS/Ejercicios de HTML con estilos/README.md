# Ejercicios de HTML con estilos

Nueve ejercicios sencillos de HTML con estilos basicos, inspirados en
https://infogonzalez.com/post-de-ejercicios-resueltos-html-nivel-medio/

Cada ejemplo es un archivo HTML independiente (basta abrirlo en el navegador) e incluye
la **URL de la fuente de los datos** utilizados.
