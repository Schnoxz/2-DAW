# Tarea 3: Matriz DAFO - CAME

- **Curso:** Itinerario Personal para la Empleabilidad II - DAW
- **Unidad:** el entorno y la competencia
- **Estado:** respuesta breve (esencial para la libreta)

## 1. ¿Qué es el DAFO?

Herramienta que hace una foto de la empresa antes de decidir qué hacer. Estudia
dos factores internos, que se pueden controlar, y dos externos, que no:

| | Positivo | Negativo |
|---|---|---|
| **Interno** | **F**ortalezas: recursos que diferencian a la empresa. | **D**ebilidades: carencias que se pueden corregir. |
| **Externo** | **O**portunidades: circunstancias que se pueden aprovechar. | **A**menazas: problemas del entorno que perjudican. |

**Ejemplos:** fortaleza, un producto más barato; debilidad, una marca nueva sin
reputación; oportunidad, una ley que obliga a un trámite que nadie cubre;
amenaza, un competidor que baja precios.

El DAFO solo describe la situación; no dice qué hacer.

## 2. La matriz CAME

Convierte el diagnóstico en acciones:

| Letra | Acción | Actúa sobre |
|---|---|---|
| **C** | Corregir | Debilidades |
| **A** | Afrontar | Amenazas |
| **M** | Mantener | Fortalezas |
| **E** | Explotar | Oportunidades |

| | Interno | Externo |
|---|---|---|
| Positivo | **M**antener fortalezas | **E**xplotar oportunidades |
| Negativo | **C**orregir debilidades | **A**frontar amenazas |

Sirve para **priorizar**: no se pueden corregir todas las debilidades ni
aprovechar todas las oportunidades a la vez.

## 3. Matriz DAFO cruzada

Cruza lo interno con lo externo y de cada cruce sale una estrategia:

| | Oportunidades (O) | Amenazas (A) |
|---|---|---|
| **Fortalezas (F)** | **FO — ofensivas:** usar fortalezas para aprovechar oportunidades. Crecimiento. | **FA — defensivas:** usar fortalezas para resistir las amenazas. |
| **Debilidades (D)** | **DO — de reorientación:** corregir debilidades aprovechando una oportunidad. Mejora. | **DA — de supervivencia:** reducir debilidades y evitar amenazas. Emergencia. |

Se usan para **ordenar prioridades y elegir la estrategia**. No se aplican las
cuatro a la vez: lo normal es una principal con apoyos de las demás.

## 4. DAFO-CAME de TachoAviso

- **Fortalezas:** aviso preventivo; minimiza datos (alias, matrícula y fechas,
  sin ficheros); cubre tacógrafo, ITV, seguro y tarjeta; precio 4-6 €/mes; plugin
  de WordPress barato.
- **Debilidades:** marca nueva, equipo unipersonal, alta manual, avisos solo por
  correo y objetivo pequeño (30-40 cuentas).
- **Oportunidades:** más de 200.000 camiones al año, normativa que no desaparece,
  sector que se digitaliza y asesorías como canal de venta.
- **Amenazas:** el Excel y la libreta son gratis; TachoTools puede añadir avisos;
  las gestorías ya lo hacen; cambios de normativa.

**CAME:** corregir con demo y prueba gratis, versión móvil y copia de seguridad;
afrontar con comparativa contra el Excel, integración con TachoTools y revisión
trimestral de la normativa; mantener los avisos a 30, 15 y 7 días y la
minimización de datos; explotar las asesorías y el contenido para transportistas.

**Estrategia elegida:** **FO** (entrar por las asesorías con precio y aviso
previo) con apoyo **DA** (costes mínimos hasta tener reputación). El problema no
es la competencia, es el sustituto gratuito.
