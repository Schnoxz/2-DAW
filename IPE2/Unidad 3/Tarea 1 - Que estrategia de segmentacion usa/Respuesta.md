# Tarea 1: ¿Qué estrategia de segmentación usa?

- **Curso:** Itinerario Personal para la Empleabilidad II - DAW
- **Unidad:** 3
- **Estado:** respuesta breve (esencial para la libreta)

## 1. Clasificación de las situaciones

Las tres estrategias son: **indiferenciada** (un solo producto y una sola campaña
para todo el mercado), **diferenciada** (productos y campañas distintos para cada
segmento) y **concentrada** (toda la oferta a un único nicho).

| Situación | Estrategia | Por qué |
|---|---|---|
| Coca-Cola, mismo refresco y campaña para todos | Indiferenciada | Un producto y un mensaje para todo el mercado. |
| Ferrari, solo deportivos de lujo | Concentrada | Un único segmento: alto poder adquisitivo. |
| Nike, líneas de running, fútbol e infantil | Diferenciada | Productos y campañas por segmento. |
| Academia solo de chino para ejecutivos | Concentrada | Todo para un grupo muy concreto. |
| Amazon, recomendaciones según el historial | Diferenciada | Oferta y comunicación adaptadas a cada cliente. |
| Pañales, mismo producto y anuncio para todos | Indiferenciada | No distingue edad ni poder adquisitivo. |
| L'Oréal, marcas para jóvenes, pieles maduras y lujo | Diferenciada | Varias marcas para segmentos distintos. |
| Clínica dental solo de ortodoncia infantil | Concentrada | Un servicio para un segmento concreto. |

## 2. Empresa real: TachoAviso

- **Segmento:** transportistas autónomos y microflotas de 1 a 10 vehículos de la
  Bahía de Algeciras y el Campo de Gibraltar.
- **Estrategia:** **concentrada**. No compito con los software de flotas: me
  centro en un nicho y resuelvo un solo problema (los vencimientos legales).
- **¿Es la adecuada?** Sí. Con pocos recursos no puedo cubrir todo el mercado, y
  la especialización me da credibilidad ante un cliente que desconfía de lo que
  no entiende.
- **Ventaja:** mensaje claro y liderazgo en el nicho con poca inversión.
- **Riesgo:** dependo de un solo segmento; si cambia la normativa o entra un
  competidor fuerte, el negocio entero se resiente.
