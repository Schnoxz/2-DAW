DOM Virtual y reconciliación

Manipular el DOM nativo del navegador es una operación lenta: obliga al motor a recalcular geometrías y repintar píxeles. React mantiene en la memoria RAM una copia ligera del DOM (el DOM virtual). Cuando los datos cambian, calcula las diferencias mínimas entre el DOM virtual y el real (reconciliación) y actualiza únicamente los nodos estrictamente necesarios.

Esta página lo simula: a la izquierda el estado que el programador quiere mostrar, a la derecha lo que realmente se toca en el DOM. Cambia el nombre de un producto y observa que se repinta un solo nodo, no toda la lista.
