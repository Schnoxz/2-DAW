Formas principales de declarar funciones

Una función es un bloque de código reutilizable que se define una vez y se invoca tantas veces como haga falta. El apartado F del tema distingue tres formas.

A. Declaración tradicional (Function Declaration)

function saludar(nombre) {
  return `Hola, ${nombre}`;
}

Disfruta de hoisting: se puede invocar antes de la línea donde está escrita.

B. Expresión de función (Function Expression)

const duplicar = function (numero) {
  return numero * 2;
};

Se asigna a una constante. No se puede usar antes de definirla.

C. Función flecha (Arrow Function, ES6)

const sumar = (a, b) => a + b;   // retorno implícito
const cuadrado = x => x * x;      // un solo parámetro sin paréntesis

Sintaxis moderna y compacta: con una sola línea el return y las llaves son implícitos.

Prueba de hoisting

Esta llamada se ejecuta antes de que el script defina nada: console.log(saludarTemprano('Ana')). Solo la forma A sobrevive, porque el motor eleva la función al inicio del ámbito.
