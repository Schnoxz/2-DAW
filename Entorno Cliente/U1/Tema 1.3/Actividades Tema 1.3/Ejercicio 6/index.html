Programación orientada a componentes (ReactJS)

La interfaz no se diseña en un bloque monolítico: se divide en piezas independientes y reutilizables llamadas componentes (un botón, una tarjeta de producto, una barra de navegación). Cada componente gestiona su propio estado (state) interno.

Comparación JSX frente a JavaScript plano

JSX es una extensión de JavaScript que permite escribir estructuras similares a etiquetas HTML dentro del código, combinando el marcado con la potencia del lenguaje.

// JSX (se compila a JavaScript) function Tarjeta(props) { return ( <div className="tarjeta"> <h3>{props.nombre}</h3> <p>{props.precio} €</p> </div> ); } // JavaScript plano: hay que crear cada nodo a mano function Tarjeta(nombre, precio) { const div = document.createElement('div'); const h3 = document.createElement('h3'); h3.textContent = nombre; div.appendChild(h3); return div; }
