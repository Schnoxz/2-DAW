La tríada fundamental: HTML + CSS + JavaScript

Cada lenguaje tiene una responsabilidad independiente. Esta página los separa en tres ficheros: index.html (estructura), estilos.css (presentación) y script.js (lógica).

1. HTML · estructura y semántica

  • Lenguaje de marcado, no de programación.
  • Define la semántica: textos, listas, campos, botones, imágenes.

2. CSS · presentación y maquetación

  • Lenguaje declarativo de diseño gráfico.
  • No interviene en la lógica ni en los datos de la web.

3. JavaScript · lógica y reactividad

  • Lenguaje dinámico, débilmente tipado y orientado a eventos.
  • Reacciona a la acción del usuario y altera el documento sin recargar.
