Actividad 3.2.1 · Recopilando información visual

Todos los datos salen del objeto raíz window y de sus propiedades. Ojo: innerWidth mide el área donde se pinta la web y screen.width mide el monitor entero, así que normalmente no coinciden.

Actividad 3.2.2 · Analizador de URLs

location ya trae la URL troceada: no hace falta parsear el texto a mano. Si abres este archivo con doble clic (file://), el protocolo será file: y el hostname aparecerá vacío; para ver una URL real hay que servirlo con un servidor local.

Actividad 3.2.3 · Online / Offline

El indicador escucha online y offline de window. Cada corte se apunta en la tabla con la hora exacta que da Temporal.Now.zonedDateTimeISO(), y el botón de emergencia usa location.replace() para no dejar la página anterior en el historial.

Actividad 3.2.4 · Autoevaluación

Cuatro preguntas con una sola respuesta correcta. Cada fallo resta un tercio de punto, así que conviene no contestar al azar.

1. ¿Qué relación existe entre window y document?
2. ¿Qué diferencia hay entre location.assign() y location.replace()?
3. ¿Qué propiedad de screen descuenta la barra de tareas del sistema?
4. ¿Por qué history no deja leer las URLs visitadas?

Actividad 3.2.5 · Enrutador SPA de navegación

Las tres secciones se pintan sin recargar el documento. pushState() crea una entrada nueva en el historial y replaceState() sobrescribe la actual: por eso cambiar de filtro varias veces y pulsar «Atrás» una sola vez devuelve a /inicio.
