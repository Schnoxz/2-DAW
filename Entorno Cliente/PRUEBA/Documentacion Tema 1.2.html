Ejercicio 1

Enunciado

Añadir un segundo botón al ejemplo de los apuntes. Al pulsarlo, no solo debe alterar el párrafo, sino que debe cambiar también el texto del encabezado <h1> mediante document.getElementById() e innerHTML.

Ejercicio 2

Enunciado

Implementar una página que capture el evento clic de un botón para emitir una traza informativa a las herramientas de desarrollo mediante console.log().

Ejercicio 3

Enunciado

Modificar el ejercicio anterior sustituyendo la escritura en el párrafo por ventanas de aviso emergentes modales, utilizando el método window.alert() o alert().

Ejercicio 4

Enunciado

Construir una web con tres botones ("Ruso", "Español", "Inglés") que alteren un párrafo (<p>) mostrando un saludo en el idioma elegido y aplicando a dicho párrafo un color de fuente CSS diferente para cada idioma mediante .style.color.

Ejercicio 5

Enunciado

Adaptar el mismo ejercicio para que las salidas en los tres idiomas se impriman únicamente a través de la consola del desarrollador.

Ejercicio 6

Enunciado

Transformar el código para generar los textos directamente en el flujo de la página mediante el método document.write().

Ejercicio 7

Enunciado

Diseñar una interfaz compuesta por un titular <h1>, un párrafo <p id="estado">Sistema en espera</p> y tres botones: Consola, para emitir una traza mediante console.log() indicando la hora del sistema; Estilo, para modificar el color de fondo del párrafo a verde y su texto a "Sistema Activo" mediante innerHTML y .style.backgroundColor; y Alerta, para lanzar un cuadro modal mediante window.alert() avisando de que el proceso ha concluido.

Ejercicio 8

Enunciado

Desarrollar un test interactivo de siete preguntas con botones "Verdadero" y "Falso". Cuando el usuario hace clic, el script evalúa el acierto y modifica la propiedad de estilo .style.color = "green" para el acierto o .style.color = "red" para el error.

Ejercicio 9

Enunciado

Crear una secuencia cíclica de al menos 4 imágenes, fotograma a fotograma. Al hacer clic sobre la imagen, el script comprueba cuál se está visualizando, mediante una condición o un contador de un array, y reasigna el atributo .src para mostrar la siguiente imagen.
